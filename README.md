# Оценка звонков администраторов

Сервис для клиники лазерной хирургии «Варикоза нет». Вы загружаете запись звонка, сервис расшифровывает её,
определяет тип звонка, оценивает работу администратора по чек-листам из стандарта работы по телефону и пишет
обратную связь: что получилось, что улучшить и какой фразой это лучше сказать.

## Как это работает

```
запись звонка (mp3/wav/…)
  → расшифровка на этом компьютере (GigaAM от Сбера, бесплатно) и разделение реплик администратора и пациента по голосу
  → определение типа звонка: входящий / заявка / онлайн-запись / напоминание / перенос / неявка / нецелевой
  → оценка ИИ по общим правилам и чек-листу сценария (через OpenRouter)
  → итоговый % (средневзвешенный), разбор по каждому пункту с цитатой, обратная связь
  → сводка по администраторам, частые ошибки, выгрузка в Excel
```

**Правила оценки** (как в вашей таблице): по каждому пункту «Да» = 100% или «Нет» = 0%, частичное выполнение
считается «Нет». Пункты с условием («если пациент отказался», «если первичный» и т.п.), когда условие не наступило,
получают «Не применимо» и в процент не входят. Итог считается средневзвешенно по значимости из регламента:
высокая = 3, средняя = 2, низкая = 1.

**Не оцениваются по записи** (видны в карточке серым): время ответа на звонок, перезвон пропущенных, интервал
звонков 10:00–20:00, ожидание 3–5 гудков, 5 дозвонов, примечания в программе, «улыбка в голосе», личный телефон,
действия в присутствии пациента. Часть из них позже можно будет брать из статистики Mango.

## Установка на компьютер в клинике (Windows)

1. Установите **Python 3.12** с <https://www.python.org/downloads/>. На первом экране установщика обязательно
   отметьте галочку **Add python.exe to PATH**.
2. Скачайте этот проект (зелёная кнопка **Code → Download ZIP** на GitHub) и распакуйте, например, в `C:\ocenka`.
3. Получите ключ OpenRouter: зарегистрируйтесь на <https://openrouter.ai>, пополните баланс (раздел Credits) и
   создайте ключ в разделе **Keys**.
4. Дважды щёлкните **`start.bat`**. При первом запуске он установит всё необходимое (несколько минут) и создаст
   файл настроек `.env`.
5. Откройте `.env` в Блокноте, впишите ключ в строку `OPENROUTER_API_KEY=` и сохраните. Закройте окно сервиса и
   снова запустите `start.bat`.
6. Сервис откроется в браузере по адресу <http://localhost:8000>.

При первой расшифровке сервис скачивает с github.com модели распознавания речи (около 270 МБ), поэтому первый
звонок обрабатывается дольше. Пятиминутный звонок расшифровывается примерно за минуту. Окно сервиса должно оставаться
открытым, пока вы с ним работаете.

**Доступ с других компьютеров клиники:** откройте `http://<IP-адрес этого компьютера>:8000` и разрешите доступ,
если Windows спросит про брандмауэр. Чтобы закрыть доступ паролем, задайте `APP_PASSWORD=` в `.env`
(логин — `admin`).

**Автозапуск при включении компьютера:** нажмите `Win + R`, введите `shell:startup` и положите в открывшуюся папку
ярлык на `start.bat`.

## Работа с сервисом

- **Звонки.** Загрузите один или несколько файлов записей из Mango, не переименовывая их: дата, время, направление
  звонка (входящий/исходящий) и телефон берутся из имени файла. Тип звонка сервис определит сам, а администратора
  найдёт по имени, которым тот представился, если сотрудник заведён на странице «Сотрудники».
- **Карточка звонка.** Итоговый процент, отдельно по общим правилам и по сценарию; обратная связь администратору;
  таблица пунктов с цитатами из разговора (можно оставить только невыполненные); расшифровка и запись. Если ИИ
  ошибся с типом звонка или администратором, исправьте это внизу карточки, и звонок переоценится.
- **Сводка.** Средний результат по каждому администратору за период и самые частые ошибки.
- **Выгрузка в Excel.** Листы «Звонки», «Пункты» (каждый пункт каждого звонка) и «Сводка».
- Вместо записи можно загрузить готовую расшифровку в `.txt` со строками вида `Администратор: …` / `Пациент: …`.

## Настройка чек-листов

Все пункты, их значимость и подсказки для ИИ лежат в [`config/checklists.yaml`](config/checklists.yaml). Его можно
править в любом текстовом редакторе (сохранять в UTF-8) и после этого перезапустить сервис.

- поменять значимость пункта: `weight: high | medium | low`; баллы за каждую значимость задаются в разделе `weights`;
- исключить пункт из оценки: `evaluable: false`;
- уточнить, как ИИ должен трактовать пункт: поле `hint`;
- **не меняйте `id` существующих пунктов**, по нему хранится история.

## Настройки (`.env`)

| Параметр | Что задаёт |
|---|---|
| `OPENROUTER_API_KEY` | ключ OpenRouter |
| `LLM_MODEL` | модель оценки звонков, по умолчанию `anthropic/claude-haiku-5.5`; точнее — `anthropic/claude-sonnet-5.5` (см. «Выбор модели») |
| `LLM_CLASSIFY_MODEL` | модель для определения типа звонка, по умолчанию Haiku |
| `LLM_PRECISE_MODEL` | модель для кнопки «Переоценить точной моделью» в карточке звонка, по умолчанию Sonnet |
| `LLM_REASONING_EFFORT` | глубина рассуждений модели: пусто, `low`, `medium` или `high` |
| `MANGO_TIME_SHIFT_HOURS` | сколько часов прибавить ко времени из имени файла Mango (оно московское), чтобы получить местное. Владивосток — `7` |
| `ASR_THREADS` | сколько ядер процессора использовать для расшифровки (0 — автоматически, до 4) |
| `DIARIZATION` | разделять администратора и пациента по голосу (`true`/`false`) |
| `STEREO_ADMIN_CHANNEL` | для стерео-записей: в каком канале администратор — `auto`, `left` или `right` |
| `MIN_CALL_SECONDS` | звонки короче этого числа секунд не оцениваются |
| `APP_PASSWORD` | пароль на веб-интерфейс |

## Как устроена расшифровка

Mango записывает разговор в моно — голоса администратора и пациента на одной дорожке. Сервис режет запись на фразы
по паузам, распознаёт каждую моделью GigaAM v2 (лучшая открытая модель для русского языка) и делит фразы на двух
собеседников по «отпечатку голоса» (модель TitaNet). Кто из них администратор, определяется по словам («клиника»,
«администратор»), а если не получилось — это решает ИИ. В расшифровке нет знаков препинания, а название клиники часто
распознаётся как «ворикоза нет» — ИИ об этом знает и оценивает по смыслу.

Если в Mango можно включить запись разговора в стерео (каждый собеседник на своём канале), сервис будет разделять
реплики без ошибок — уточните это в поддержке Mango.

## Выбор модели и стоимость

Расшифровка бесплатная — работает на процессоре этого компьютера. Платная только оценка через OpenRouter.

Сервис проверен на 5 реальных записях клиники (октябрь 2026): каждую оценку независимо перепроверял более
сильный ИИ-эксперт по каждому пункту чек-листа.

| | Claude Haiku 5.5 | Claude Sonnet 5.5 |
|---|---|---|
| Тип звонка определён верно | 5 из 5 | 5 из 5 |
| Явные ошибки в пунктах | 6 из 244 (2,5%) | 0 из 244 |
| Обратную связь можно отдать администратору без правок | 2 звонка из 5 | 4 звонка из 5 |
| Среднее отклонение итогового % от проверяющего | 6,6 | 3,3 |
| Стоимость звонка 3–6 минут | ≈ $0.003 (≈ 0,3 ₽) | ≈ $0.05–0.07 (≈ 4–6 ₽) |
| 1000 звонков в месяц | ≈ 300 ₽ | ≈ 5–6 тыс. ₽ |

Тип звонка всегда определяет дешёвая модель (`LLM_CLASSIFY_MODEL`). Можно оценивать все звонки на Haiku, а спорные
переоценивать кнопкой «Переоценить точной моделью» — или сразу поставить `LLM_MODEL=anthropic/claude-sonnet-5.5`.
Фактическая стоимость каждого звонка показана внизу его карточки.

## Если что-то не работает

- **«Не удалось скачать модели расшифровки».** Проверьте, что с этого компьютера открывается github.com.
  Можно скачать модели на другом компьютере и положить в папку `data\models` (список файлов — в `app/transcription.py`,
  `MODEL_FILES`).
- **«OpenRouter отклонил запрос — model not found».** Проверьте название модели в `LLM_MODEL` на
  <https://openrouter.ai/models>.
- **«HTTP 402».** Закончился баланс OpenRouter.
- **Ошибка при установке зависимостей в Windows.** Установите
  [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) и запустите `start.bat` ещё раз.

## Для разработчика

```bash
pip install -r requirements-dev.txt
python -m pytest        # тесты (расшифровка и ИИ подменены)
python -m app           # запуск
```

Код: `app/web.py` (веб-интерфейс), `app/pipeline.py` (очередь обработки), `app/transcription.py` (расшифровка),
`app/evaluation.py` (запросы к ИИ и разбор ответов), `app/scoring.py` (расчёт процента), `app/reports.py`
(сводка и Excel), `app/db.py` (база SQLite в `data/`).
